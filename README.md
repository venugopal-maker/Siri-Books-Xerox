# Xerox Shop Website

## Project Overview
A responsive website developed for a local Xerox and printing shop as a free website development project.

The website helps customers explore the shop's services, view available printing options, and contact the shop easily.

## Features
- Home page with shop introduction
- Services and pricing section
- Xerox and photocopy services
- Colour and black & white printing
- Scanning and document services
- Passport-size photo services
- Contact details and Google Maps location
- Mobile-friendly responsive design

## Technologies Used
- HTML5
- CSS3


## Project Type
Real-World Client Project – Free Website Development

## Purpose
To provide a local business with an online presence and make its services easier for customers to discover.
